# KAN-158 Complete October Sobeys receipt extraction review

Jira: [KAN-158](https://brownrook.atlassian.net/browse/KAN-158)

## User story

As the person reviewing household receipts, I want reliable receipt fields and
line items, with unresolved readings clearly flagged, so that I can trust the
ledger and spend less time correcting extraction errors.

## Delivered behavior

General fixes cover OCR evidence alignment, cache reading order, page overlap,
item amounts and adjustments, store/contact/address extraction and provenance.
Receipt list and detail show current reprocessing progress across refreshes.
The main **Reprocess receipt** action reuses a valid OCR cache automatically;
missing or invalid cache triggers OCR. **Advanced → Reread original document**
forces fresh OCR. Refreshing the browser reloads saved results and progress.
Operational timestamps display local time without a timezone suffix.

[PR #256](https://github.com/larocquemb/home-budget-pipeline/pull/256) contains the
preceding extraction, progress and trace-discovery implementation. The final
cache/address/automatic-processing changes are linked from Jira at closeout.
